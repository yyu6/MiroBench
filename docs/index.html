§ 01 — Overview

What LLMs don't get right.

LLMs fail on thread branching, neutral tone, lexical diversity, length variance, and stance disagreement. MiroBench measures the gap and helps you close it.

01 — SCORE

Score your generated threads

$ mirobench score <dir>
02 — COMPARE

MWU · KS · Cliff's δ · Wasserstein

$ mirobench compare scores.csv
03 — CALIBRATE

Auto-tune prompt overlays with an LLM

$ python -m calibration

§ 04 — Quick start
01 Install
install.sh 
$ git clone https://github.com/yyu6/MiroBench.git
$ cd MiroBench
$ pip install -e .
02 Score your threads
score.sh 
# each thread = dir with discussion.json
$ mirobench score my_threads/ --device cpu
→ my_threads/thread_scores.csv
03 Compare against real Reddit
compare.sh 
$ mirobench compare my_threads/thread_scores.csv \
    --domains credit_cards cameras \
    --core-only \
    --model-name "my-model"

§ 05 — Calibration

An LLM that tunes your overlay.

0
BASELINE

Score vanilla simulation

1
ITERATE

Reasoner edits overlay each round

2
FINAL

Re-run + before/after report

Calibration CLI
calibrate.sh 
$ python -m calibration \
    --real-train-csv mirobench/data/credit_cards/reference_scores/thread_scores_train.csv \
    --real-val-csv   mirobench/data/credit_cards/reference_scores/thread_scores_val.csv \
    --real-test-csv  mirobench/data/credit_cards/reference_scores/thread_scores_test.csv \
    --few-shot-dir   path/to/real_discussions/ \
    --products-json  path/to/products.json \
    --output-dir     calibration_runs/credit_cards \
    --calibration-model gpt-4o-mini \
    --iterations 12 --candidates 5 \
    --final-sim-runs 9 --min-sim-threads 50
